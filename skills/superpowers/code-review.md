---
name: Code review
command: review
description: Review completed work against the plan and quality bar
---
Review the change against the plan or requirement:
- Does it do what was asked, no more and no less?
- Are there correctness, error-handling, security or concurrency issues?
- Are there tests, and do they test behaviour?
Report blockers, majors and minors with file:line and a fix. When you receive a review, verify each point
technically before acting. Push back with evidence when a suggestion is wrong.
