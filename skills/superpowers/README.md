# Superpowers workflow (on demand)

Concise rewrites of the workflow popularised by [obra/superpowers](https://github.com/obra/superpowers) (MIT).
None of these files is sent to agents by default:
- `/superpowers` toggles the workflow for a chat. Only the short index (`superpowers-index`) is sent on each new session.
- `/brainstorm`, `/plan`, `/execute`, `/tdd`, `/debug`, `/review` and `/verify` load a single skill for one message.
