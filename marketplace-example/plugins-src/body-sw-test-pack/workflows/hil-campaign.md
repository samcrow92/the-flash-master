---
name: HIL campaign
command: hil-campaign
description: Prepare, run and report a HIL test campaign
---
1. List the requirements in scope and the matching CANoe test modules; flag requirements without coverage.
2. Check the bench configuration (CANoe config, ECU software version) before running.
3. Run the campaign, then report: pass/fail per module, new failures vs. the last campaign, and blocking defects with Jazz IDs.
